This animation is basically a mouse-interactive particle grid background. When the cursor moves, nearby dots change color and get pushed away with inertia, and when you click it creates a shockwave effect. It’s a strong hero background animation.
But before using it, you need to understand what it does, where to use it, and what to modify. Otherwise it will either look out of place or kill performance.
1. What This Animation Actually Does
Your component DotGrid:
Draws hundreds of dots on a canvas
Detects cursor proximity
Changes color when cursor approaches
Applies GSAP inertia physics
Creates shockwave on click
Interaction Effects
Mouse movement
→ nearby dots shift and glow
Fast cursor movement
→ dots scatter slightly
Mouse click
→ circular shockwave
This makes the page feel alive and reactive.

Use this ONLY in the hero section background.

6. Important Performance Warning
This animation renders hundreds of dots per frame.
If you use:
dotSize=5
gap=15

You might generate 1500+ particles.
That can lag on phones.
Safer values
dotSize = 6
gap = 22

This reduces particles by almost 50%.

7. Parameters Explained
dotSize
Size of each dot.
dotSize={5}

Smaller = more elegant.

gap
Distance between dots.
gap={15}

Lower gap = more particles.

proximity
Distance where dots react to cursor.
proximity={120}

Higher = larger interaction radius.

shockRadius
Click explosion radius.
shockRadius={250}

shockStrength
Explosion intensity.
shockStrength={5}

resistance
Controls inertia friction.
resistance={750}

Higher = slower return.

returnDuration
How fast dots return.
returnDuration={1.5}

This component is a WebGL curved scrolling gallery built using OGL (WebGL library). It’s not a simple React animation — it’s basically a mini 3D engine rendering image planes that bend in an arc and move with scroll/drag.
Used correctly, it can look very impressive. Used incorrectly, it becomes unnecessary complexity. So let’s break it down properly.
1. What This Animation Does
Your CircularGallery renders:
Images as WebGL planes
Arranged in a curved arc (circular illusion)
Scroll or drag → gallery moves
Images warp slightly with movement
Each image has text title below it
Interaction:
mouse wheel → scroll
drag → move gallery
items wrap infinitely
Visually it looks like:
        [Speech]

  [Essay]       [Quiz]

        [Poetry]

Curved like a carousel arc.

That’s exactly where this works well.
Instead of boring cards like:

You get an interactive gallery.
Users can drag through competitions.
